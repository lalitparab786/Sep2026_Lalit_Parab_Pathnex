AWS Auto-scaler

AWS Auto Scaling is an AWS service which is responsible to increases or decreases Node based on demand.

Karpenter is a Kubernetes node auto-scaling tool that automatically provisions (creates) and removes worker nodes based on pod requirements

Karpenter directly calls AWS EC2 APIS, No Auto Scaling Group is required.

Keda KEDA automatically scales pods based on events from external systems like Kafka KEDA does not directly increase Pods it tell HPA to perform the scaling.

HPA HPA (Horizontal Pod Autoscaler) is a Kubernetes component that automatically increases or decreases the number of Pods based on metrics such as CPU, memory, or custom metrics.

Initial 3 pod > Traffic suddenly increases (CPU Usage 85%) > Pods 36 also scale down

Metrics Serve that collects CPU and Memory usage from nodes and pods and provides this data to HPA so that HPA can decide whether to scale pods.

Metrics Server provides resource metrics only: CPU Usage, Memory Usage.

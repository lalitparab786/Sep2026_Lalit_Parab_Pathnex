Terraform State: Terraform State is JSON a file that Terraform uses to keep track of the infrastructure it manages. It stores the current state of infrastructure managed by Terraform. Update post Terraform apply, If fail then not updated

When you run: terraform apply: Terraform creates resources (EC2, VPC, EKS, etc.) and stores information about those resources in a state file. 1. "Terraform state list" Total state file will show 2. "Terraform state show Resource name" Shows content in that resource
